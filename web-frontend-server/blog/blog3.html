Bài 3: Bảo mật API với Keycloak OIDC

Triển khai định danh tập trung (Identity and Access Management - IAM) thông qua Keycloak 24+:

  • Realm: Khởi tạo realm riêng biệt phục vụ người dùng sinh viên.
  • Client: Client flask-app hỗ trợ Direct Access Grants (Password Grant) để lấy JWT Bearer token trực tiếp.
  • User: Đã cấu hình sẵn 2 tài khoản sinh viên sv01 và sv02 với mật khẩu chuẩn.
  • Protected Endpoint: Route /secure kiểm tra tính hợp lệ của token trước khi phản hồi dữ liệu.
