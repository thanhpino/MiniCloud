Bài 2: Cơ chế Giám sát với Prometheus & Grafana

Hệ thống giám sát MiniCloud cung cấp khả năng quan sát (observability) thời gian thực toàn diện:

  • Prometheus (Port 9090): Định kỳ mỗi 15s scrape dữ liệu từ Node Exporter (Port 9100) và Web Frontend (Port 80).
  • Node Exporter: Thu thập thông số hạt nhân Linux của máy chủ (CPU idle, RAM available, Network transmit/receive).
  • Grafana Dashboard (Port 3000): Tự động nạp dashboard System Health qua file provisioning, hiển thị biểu đồ CPU, RAM, Network I/O.
