Bài 1: Kiến trúc Hạ tầng 9 Server MiniCloud

Dự án MiniCloud được thiết kế mô phỏng kiến trúc Microservices & Cloud Infrastructure hoàn chỉnh gồm 9 máy chủ chuyên biệt:

  • API Gateway (Nginx): Điểm truy cập duy nhất tại cổng 80, cân bằng tải Round Robin giữa Web 1 và Web 2.
  • DNS Server (Bind9): Phân giải tên miền nội bộ cloud.local cho các container.
  • Monitoring (Prometheus & Grafana): Thu thập số liệu hiệu năng qua Node Exporter.
  • Security (Keycloak): Máy chủ xác thực người dùng OIDC/OAuth2.
  • Data & Storage: MariaDB cho cơ sở dữ liệu quan hệ và MinIO cho Object Storage S3-compatible.
